## Overview

Create the local monorepo skeleton for the personal RSJT project. This ticket establishes workspace commands, local-only environment configuration, API/mobile/shared/db package boundaries, and local PostgreSQL wiring without implementing product behavior.

## Proposed Structure

- Use pnpm workspaces with `apps/mobile`, `apps/api`, `packages/shared`, and `packages/db`.
- Keep generated app code minimal until later tickets add product flows.
- Use root scripts for `lint`, `typecheck`, `test`, and local database startup.
- Keep all infrastructure local or personal. Do not add Linear, Notion, Slack, Gmail, Google Drive, or Tenex-owned configuration.
- Use Expo Go first for mobile development unless a later implementation plan proves a development build is required.

## File-By-File Change List

### `package.json`

**Change:** Create root package and workspace scripts.

```json
{
  "name": "rsjt",
  "private": true,
  "packageManager": "pnpm@9.15.4",
  "scripts": {
    "db:up": "docker compose up -d postgres",
    "db:down": "docker compose down",
    "lint": "biome check .",
    "lint:fix": "biome check --write .",
    "test": "pnpm -r --if-present test",
    "typecheck": "pnpm -r --if-present typecheck"
  },
  "devDependencies": {
    "@biomejs/biome": "^1.9.4",
    "typescript": "^5.8.3",
    "vitest": "^3.1.4"
  }
}
```

**Why:** Provides one local command surface for the repo without adding remote services.

### `docker-compose.yml`

**Change:** Add local PostgreSQL only.

```yaml
services:
  postgres:
    image: postgres:16-alpine
    restart: unless-stopped
    ports:
      - "54329:5432"
    environment:
      POSTGRES_DB: rsjt_dev
      POSTGRES_USER: rsjt
      POSTGRES_PASSWORD: rsjt_local
    volumes:
      - rsjt_postgres:/var/lib/postgresql/data

volumes:
  rsjt_postgres:
```

**Why:** Gives the API and database package a predictable local development database without managed infrastructure.
