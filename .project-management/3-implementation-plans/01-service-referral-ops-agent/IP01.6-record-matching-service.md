# IP01.6 - Record Matching Service - Implementation Plan

**Date:** 2026-05-19
**Story Points:** 8
**Project Plan:** PP01-service-referral-ops-agent
**Local Ticket:** RSJT-006
**Dependencies:** RSJT-005

## Overview

Build the first app-owned RepairShopr record matching service. The service will accept partial customer and job hints, search the existing read-only RepairShopr client, score candidates with visible reasons, persist candidate decisions locally, and expose authenticated API routes for search, selection, and unlinking.

This ticket must not write to RepairShopr. It only reads RepairShopr and updates local app state in Postgres.

The code must keep role vocabulary generic. Use `manager` and `tech` only where auth requires roles. Do not introduce person names in code, DB enums, route guards, fixtures, or test identities.

## Proposed Structure

- Add shared request and response schemas for matching under `packages/shared/src/domain/matching.ts`.
- Keep score thresholds in `packages/shared/src/domain/confidence.ts` as the single source of truth.
- Add a narrow DB migration so persisted candidates can round-trip the full shared `RepairShoprReferenceSchema`, including `displayLabel` and optional `url`.
- Add `MatchesRepository` for local persistence only.
- Add `MatchingService` for search orchestration across customers, contacts, leads, active work, and recent activity, plus candidate scoring, confidence banding, single-candidate display linking, selection, and unlinking.
- Treat candidate refresh as a new matching decision cycle: replace candidates and clear any previously selected local RepairShopr job link.
- Add `matches-routes.ts` with authenticated routes:
  - `GET /jobs/:jobId/matches`
  - `POST /jobs/:jobId/matches/search`
  - `POST /jobs/:jobId/matches/:candidateId/select`
  - `DELETE /jobs/:jobId/matches/selection`
- Allow both `manager` and `tech` authenticated users to see and select matches in v1. This is local matching state, not an external writeback.
- Keep route tests fixture-backed and service tests dependency-injected. Do not require live RepairShopr calls or RepairShopr credentials for the default test suite.

## Non-Goals

- Do not create or update RepairShopr customers, leads, tickets, appointments, comments, invoices, or payments.
- Do not add Twilio intake behavior.
- Do not add AI extraction behavior.
- Do not add mobile UI.
- Do not introduce a global fuzzy-search dependency before the simple scorer has proven insufficient.

### `apps/api/src/repositories/matches-repository.ts`

**Change:** Add local persistence for match candidates, selection, and unlinking.

Proposed structure:

```ts
import type { AppDb } from "@rsjt/db";
import { jobs, matchCandidates } from "@rsjt/db";
import {
  MatchConfidenceBandSchema,
  MatchReasonSchema,
  RepairShoprEntityTypeSchema,
  type MatchCandidate,
  type RepairShoprReference,
} from "@rsjt/shared";
import { and, eq, isNotNull } from "drizzle-orm";

type StoredMatchCandidate = MatchCandidate & {
  selectedAt: Date | null;
};

export type MatchCandidateStore = {
  replaceForJob(jobId: string, candidates: MatchCandidate[]): Promise<void>;
  listForJob(jobId: string): Promise<StoredMatchCandidate[]>;
  selectForJob(
    jobId: string,
    candidateId: string,
  ): Promise<RepairShoprReference | null>;
  clearSelection(jobId: string): Promise<void>;
  getSelectedReference(jobId: string): Promise<RepairShoprReference | null>;
};

export class MatchesRepository implements MatchCandidateStore {
  constructor(private readonly db: AppDb) {}

  async replaceForJob(jobId: string, candidates: MatchCandidate[]) {
    await this.db.transaction(async (tx) => {
      await tx
        .update(jobs)
        .set({
          repairShoprEntityType: null,
          repairShoprId: null,
          customerLabel: null,
          updatedAt: new Date(),
        })
        .where(eq(jobs.id, jobId));

      await tx.delete(matchCandidates).where(eq(matchCandidates.jobId, jobId));

      if (candidates.length === 0) {
        return;
      }

      await tx.insert(matchCandidates).values(
        candidates.map((candidate) => ({
          id: candidate.id,
          jobId,
          repairShoprEntityType: candidate.repairShoprReference.entityType,
          repairShoprId: candidate.repairShoprReference.repairShoprId,
          repairShoprDisplayLabel:
            candidate.repairShoprReference.displayLabel,
          repairShoprUrl: candidate.repairShoprReference.url ?? null,
          confidence: Math.round(candidate.confidence * 10000),
          confidenceBand: candidate.confidenceBand,
          reasons: candidate.reasons,
        })),
      );
    });
  }

  async listForJob(jobId: string): Promise<StoredMatchCandidate[]> {
    const rows = await this.db
      .select()
      .from(matchCandidates)
      .where(eq(matchCandidates.jobId, jobId));

    return rows.map(toStoredCandidate);
  }

  async selectForJob(jobId: string, candidateId: string) {
    return this.db.transaction(async (tx) => {
      const [candidate] = await tx
        .select()
        .from(matchCandidates)
        .where(
          and(
            eq(matchCandidates.jobId, jobId),
            eq(matchCandidates.id, candidateId),
          ),
        )
        .limit(1);

      if (!candidate) {
        return null;
      }

      await tx
        .update(matchCandidates)
        .set({ selectedAt: null })
        .where(eq(matchCandidates.jobId, jobId));

      await tx
        .update(matchCandidates)
        .set({ selectedAt: new Date() })
        .where(
          and(
            eq(matchCandidates.jobId, jobId),
            eq(matchCandidates.id, candidateId),
          ),
        );

      const reference = toReference(candidate);

      await tx
        .update(jobs)
        .set({
          repairShoprEntityType: reference.entityType,
          repairShoprId: reference.repairShoprId,
          customerLabel: reference.displayLabel,
          updatedAt: new Date(),
        })
        .where(eq(jobs.id, jobId));

      return reference;
    });
  }

  async clearSelection(jobId: string) {
    await this.db.transaction(async (tx) => {
      await tx
        .update(matchCandidates)
        .set({ selectedAt: null })
        .where(eq(matchCandidates.jobId, jobId));

      await tx
        .update(jobs)
        .set({
          repairShoprEntityType: null,
          repairShoprId: null,
          customerLabel: null,
          updatedAt: new Date(),
        })
        .where(eq(jobs.id, jobId));
    });
  }

  async getSelectedReference(jobId: string) {
    const [candidate] = await this.db
      .select()
      .from(matchCandidates)
      .where(
        and(
          eq(matchCandidates.jobId, jobId),
          isNotNull(matchCandidates.selectedAt),
        ),
      )
      .limit(1);

    return candidate ? toReference(candidate) : null;
  }
}

type MatchCandidateRow = typeof matchCandidates.$inferSelect;

function toStoredCandidate(row: MatchCandidateRow): StoredMatchCandidate {
    return {
      id: row.id,
      confidence: row.confidence / 10000,
      confidenceBand: MatchConfidenceBandSchema.parse(row.confidenceBand),
      reasons: MatchReasonSchema.array().parse(row.reasons),
      repairShoprReference: toReference(row),
      selectedAt: row.selectedAt,
  };
}

function toReference(row: MatchCandidateRow): RepairShoprReference {
  return {
    entityType: RepairShoprEntityTypeSchema.parse(row.repairShoprEntityType),
    repairShoprId: row.repairShoprId,
    displayLabel: row.repairShoprDisplayLabel,
    url: row.repairShoprUrl ?? undefined,
  };
}
```

**Why:** Keeps all local matching persistence in one repository and keeps RepairShopr writes impossible from the matching service.

Proposed service behavior:

```ts
export class MatchingService implements MatchingServiceApi {
  constructor(
    private readonly store: MatchCandidateStore,
    private readonly repairShopr: RepairShoprMatchReader,
    private readonly now: () => Date = () => new Date(),
    private readonly createId: () => string = randomUUID,
  ) {}

  async listJobMatches(jobId: string): Promise<MatchSearchResponse> {
    const candidates = await this.store.listForJob(jobId);
    return buildSearchResponse(jobId, candidates);
  }

  async searchJobMatches(
    jobId: string,
    input: MatchSearchInput,
  ): Promise<MatchSearchResponse> {
    const records = await this.searchRepairShopr(input);
    const candidates = scoreRecords(input, records, this.createId);

    await this.store.replaceForJob(jobId, candidates);

    return buildSearchResponse(jobId, candidates);
  }

  async selectMatch(
    jobId: string,
    candidateId: string,
  ): Promise<MatchSelectionResponse> {
    const repairShoprReference = await this.store.selectForJob(
      jobId,
      candidateId,
    );

    if (!repairShoprReference) {
      throw new MatchCandidateNotFoundError();
    }

    return {
      jobId,
      selectedCandidateId: candidateId,
      repairShoprReference,
    };
  }

  async unlinkMatch(jobId: string): Promise<MatchSelectionResponse> {
    await this.store.clearSelection(jobId);

    return {
      jobId,
      selectedCandidateId: null,
      repairShoprReference: null,
    };
  }
}
```

Candidate scoring and de-duplication:

```ts
type ScoreableRecord = {
  reference: RepairShoprReference;
  customerId?: number | null;
  contactId?: number | null;
  phone?: string | null;
  mobile?: string | null;
  email?: string | null;
  name?: string | null;
  address?: string | null;
  hasActiveWork?: boolean;
  hasRecentActivity?: boolean;
};

function scoreRecords(
  input: MatchSearchInput,
  records: ScoreableRecord[],
  createId: () => string,
): MatchCandidate[] {
  return dedupeByReference(records)
    .map((record) => scoreRecord(input, record, createId))
    .filter((candidate) => candidate.reasons.length > 0)
    .sort((a, b) => b.confidence - a.confidence);
}

function dedupeByReference(records: ScoreableRecord[]) {
  const seen = new Set<string>();
  return records.filter((record) => {
    const key = `${record.reference.entityType}:${record.reference.repairShoprId}`;
    if (seen.has(key)) {
      return false;
    }

    seen.add(key);
    return true;
  });
}

function scoreRecord(
  input: MatchSearchInput,
  record: ScoreableRecord,
  createId: () => string,
): MatchCandidate {
  const reasons: MatchReason[] = [];

  if (input.phone && phoneMatches(input.phone, record.phone, record.mobile)) {
    reasons.push(reason("Phone match", "Phone or mobile matches.", "exactPhone"));
  }

  if (input.email && emailsMatch(input.email, record.email)) {
    reasons.push(reason("Email match", "Email address matches.", "exactEmail"));
  }

  if (input.name && namesOverlap(input.name, record.name)) {
    reasons.push(reason("Name match", "Name tokens overlap.", "name"));
  }

  if (input.address && addressesOverlap(input.address, record.address)) {
    reasons.push(reason("Address match", "Address text overlaps.", "address"));
  }

  if (record.hasActiveWork) {
    reasons.push(reason("Active work", "Open RepairShopr work is present.", "activeWork"));
  }

  if (record.hasRecentActivity) {
    reasons.push(reason("Recent activity", "Recent RepairShopr activity is present.", "recentActivity"));
  }

  const confidence = Math.min(
    1,
    reasons.reduce((sum, item) => sum + item.weight, 0),
  );

  return {
    id: createId(),
    confidence,
    confidenceBand: confidenceBandForScore(confidence),
    reasons,
    repairShoprReference: record.reference,
  };
}
```

Candidate response rules:

```ts
function confidenceBandForScore(score: number): MatchConfidenceBand {
  if (score >= MatchConfidenceThresholds.high) {
    return "high";
  }

  if (score >= MatchConfidenceThresholds.mediumHigh) {
    return "medium_high";
  }

  return "low";
}

function buildSearchResponse(
  jobId: string,
  candidates: MatchCandidate[],
): MatchSearchResponse {
  const linkableCandidates = candidates.filter(
    (candidate) => candidate.confidence >= MatchConfidenceThresholds.mediumHigh,
  );
  const [displayLinkedCandidate] = linkableCandidates;

  return {
    jobId,
    candidates,
    displayLinkedCandidateId:
      linkableCandidates.length === 1 && displayLinkedCandidate
        ? displayLinkedCandidate.id
        : null,
    requiresConfirmation: linkableCandidates.length !== 1,
  };
}
```

**Why:** The service keeps matching deterministic and explainable. The scoring constants are local to the service because they are implementation weights, while threshold values remain shared because they affect product behavior.

```ts
import {
  JobIdParamsSchema,
  MatchCandidateParamsSchema,
  MatchSearchRequestSchema,
} from "@rsjt/shared";
import type { FastifyInstance } from "fastify";
import {
  MatchCandidateNotFoundError,
  type MatchingServiceApi,
} from "../services/matching-service.js";

export async function registerMatchRoutes(
  app: FastifyInstance,
  matchingService?: MatchingServiceApi,
) {
  function requireMatchingService() {
    if (!matchingService) {
      throw app.httpErrors.serviceUnavailable("Matching service unavailable");
    }

    return matchingService;
  }

  app.get("/jobs/:jobId/matches", async (request) => {
    await app.requireUser(request);
    const { jobId } = JobIdParamsSchema.parse(request.params);
    return requireMatchingService().listJobMatches(jobId);
  });

  app.post("/jobs/:jobId/matches/search", async (request) => {
    await app.requireUser(request);
    const { jobId } = JobIdParamsSchema.parse(request.params);
    const { input } = MatchSearchRequestSchema.parse(request.body);
    return requireMatchingService().searchJobMatches(jobId, input);
  });

  app.post("/jobs/:jobId/matches/:candidateId/select", async (request) => {
    await app.requireUser(request);
    const { jobId, candidateId } = MatchCandidateParamsSchema.parse(
      request.params,
    );
    try {
      return await requireMatchingService().selectMatch(jobId, candidateId);
    } catch (error) {
      if (error instanceof MatchCandidateNotFoundError) {
        throw app.httpErrors.notFound("Match candidate not found");
      }

      throw error;
    }
  });

  app.delete("/jobs/:jobId/matches/selection", async (request) => {
    await app.requireUser(request);
    const { jobId } = JobIdParamsSchema.parse(request.params);
    return requireMatchingService().unlinkMatch(jobId);
  });
}
```

**Why:** These routes expose match data to app flows without exposing RepairShopr credentials and without adding any RepairShopr write path.

## Matching Algorithm Details

### Input Normalization

- Phone: strip non-digits and compare the last 10 digits when possible.
- Email: lowercase and trim.
- Name: lowercase, trim, split on whitespace, and require token overlap.
- Address: lowercase, trim, collapse whitespace, and compare meaningful substrings.
- Ticket number: trim and pass to `listTickets({ number })`.

### Candidate Collection

Use only read methods from `RepairShoprClient`:

- `listCustomers({ phone })`, `listCustomers({ mobile })`, `listCustomers({ email })`, and `listCustomers({ query })`
- `listContacts({ customer_id })` when a customer candidate is known, plus local scoring of returned contact phone, email, and name fields
- `listLeads({ query })`
- `listTickets({ number })`
- `listTickets({ customer_id })` and `listTickets({ contact_id })` for active work on known candidate records
- `listAppointments({ date_from, date_to })` for recent activity, filtered locally by candidate IDs
- `listInvoices({ since_updated_at })` for recent activity, filtered locally by candidate IDs
- `listPayments({ query })` for recent payment context

Do not add write methods. Do not call any non-GET RepairShopr operation.

### Scoring

Reasons are additive and capped at `1.0`:

```ts
const score = Math.min(
  1,
  reasons.reduce((sum, reason) => sum + reason.weight, 0),
);
```

Banding uses the existing shared constants:

- `high`: `score >= MatchConfidenceThresholds.high`
- `medium_high`: `score >= MatchConfidenceThresholds.mediumHigh`
- `low`: below `mediumHigh`

### Display Linking

- Exactly one candidate at or above `mediumHigh` can be display-linked.
- Multiple candidates at or above `mediumHigh` require confirmation.
- Low confidence candidates require confirmation or more information.
- Matching never executes RepairShopr writeback.
