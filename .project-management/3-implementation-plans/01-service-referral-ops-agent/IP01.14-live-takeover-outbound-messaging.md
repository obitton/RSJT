# IP01.14 - Live Takeover And Outbound Messaging - Implementation Plan

**Date:** 2026-05-26
**Story Points:** 8
**Project Plan:** PP01-service-referral-ops-agent
**Local Ticket:** RSJT-014
**Dependencies:** RSJT-011, RSJT-012, RSJT-013

## Overview

Add live takeover controls and the outbound messaging service boundary. The tech role should be able to activate takeover for a customer conversation, view the transcript, draft a reply, and send through the backend outbound messaging service when outbound messaging is explicitly enabled. While takeover is active, automated intake prompts must pause. The manager dashboard should show takeover state and stale takeover warnings.

The implementation must keep real sends disabled by default. It can include the Twilio send code path behind `MESSAGING_OUTBOUND_ENABLED`, but local tests must use fakes and fixture assertions. Do not send live SMS or WhatsApp messages from tools.

Fresh documentation check:

- Twilio Messages resource docs were checked on 2026-05-26. Outbound sends are created through the Message resource and can return an initial status.
- Twilio Node send docs confirm the SDK shape for `client.messages.create`.
- Twilio status callback docs confirm the initial status is not sent as a status callback and should be read from the create response.
- Expo Router docs confirm nested dynamic routes such as `src/app/(tech)/tech/conversations/[conversationId].tsx` map to `/tech/conversations/:conversationId`.
- TanStack Query mutation guidance matches the existing app pattern for outbound actions.

## Proposed Structure

- Add shared conversation and outbound message DTOs.
- Extend message persistence to support outbound draft/send state and status updates.
- Add takeover service methods for activate, release, list conversations, get transcript, and send outbound message.
- Add a Twilio outbound adapter that is disabled unless config explicitly enables it.
- Update customer intake processing so automated prompt staging pauses while takeover is active.
- Add tech mobile conversation list and transcript screens with a takeover toggle and composer.
- Surface active takeover conversations on the manager dashboard from IP01.11.

## API Shape

### `GET /tech/conversations`

Requires `tech` or `manager` role.

Returns customer conversations sorted by recent activity.

### `GET /tech/conversations/:conversationId`

Requires `tech` or `manager` role.

Returns conversation detail and transcript.

### `POST /tech/conversations/:conversationId/takeover`

Requires `tech` or `manager` role.

Body:

```json
{
  "active": true
}
```

### `POST /tech/conversations/:conversationId/messages`

Requires `tech` or `manager` role.

Body:

```json
{
  "body": "Thanks, I can help with that. I will review the schedule and follow up."
}
```

Behavior:

- Requires takeover to be active.
- Requires `MESSAGING_OUTBOUND_ENABLED=true` for a real Twilio call.
- Returns `409` when outbound messaging is disabled.
- Persists outbound attempts and returned Twilio status when sends are enabled.
